# FTMotion Yönetim V5

GitHub deposunda sadece `yonetim.html` dosyasını değiştirmeniz yeterli. Supabase tarafında yeni tablo veya SQL değişikliği gerekmez. Mevcut `site_settings`, `businesses`, `orders` tablolarını kullanır. QR ve menü panellerinin müşteri bazında canlı veri yönetimi henüz tamamlanmadı. Görsel/video için HTTPS URL gerekir. Site alt sayfalarının Supabase veri senkronizasyonu ayrıca tamamlanmalıdır.
