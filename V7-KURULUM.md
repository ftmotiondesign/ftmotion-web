# FTMotion V7 — Esnek Kampanyalar

1. Önce V6 SQL kurulumu çalışmış olmalı.
2. Supabase SQL Editor'de `V7-KAMPANYA-SQL.sql` dosyasını çalıştırın.
3. GitHub'da `kampanya.html`, `yonetim.html`, `paket-yonetimi.html` dosyalarını depo ana klasörüne yükleyin.
4. `paket-yonetimi.html` ekranından sektör bazlı paketler oluşturun.
5. `kampanya.html` sayfasında yayınlanan paketleri kontrol edin.

Dijital menü yalnızca seçtiğiniz paketlerde yer alır.
Kampanya fiyatları Supabase tablosunda tutulur. Teklif isteği WhatsApp'a yönlenir, otomatik sipariş kaydı oluşturmaz.
Mevcut `siparis.html` içindeki eski altılı kampanya mantığı henüz değiştirilmemiştir; paket tekliflerini bu yüzden yeni kampanya ekranındaki WhatsApp butonundan gönderin.
